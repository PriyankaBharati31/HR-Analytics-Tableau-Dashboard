# HR Analytics Dashboard Using Tableau

## Overview

This project is an interactive HR Analytics Dashboard created using Tableau to analyze employee attrition, workforce demographics, salary trends, and departmental performance.

The dashboard helps organizations understand employee turnover patterns and supports better HR decision-making through data visualization and insights.

---

## Key Features

* Employee Attrition Analysis
* Department-wise Performance Tracking
* Salary & Compensation Analysis
* Age Distribution Insights
* Employee Tenure Analysis
* Interactive Tableau Dashboards

---

## Tools & Technologies

* Tableau Desktop
* Tableau Public
* Microsoft Excel

---

## Dataset

**Dataset Used:** WA_Fn-UseC_-HR-Employee-Attrition

The dataset contains employee information such as:

* Age
* Department
* Job Role
* Monthly Income
* Attrition Status
* Business Travel
* Years at Company

---

## Dashboards Included

1. Executive Overview
2. Attrition Analysis
3. Demographic & Compensation Analysis
4. Department Performance Metrics

---

## Key Insights

* Certain departments experienced higher attrition rates.
* Employee salary and tenure influenced retention trends.
* Business travel showed an impact on employee attrition.

---

## Conclusion

This project demonstrates how Tableau dashboards can help organizations analyze HR data, identify workforce trends, and improve employee retention strategies.
