HR Analytics Dashboard Using Tableau
Overview

Employee attrition is one of the major challenges faced by organizations. Understanding workforce behavior and identifying factors affecting employee retention can help businesses improve employee satisfaction and reduce turnover.

This project uses Tableau to create interactive dashboards for analyzing HR data and generating valuable workforce insights.

Objectives
Analyze employee attrition patterns
Visualize workforce demographics
Study salary and compensation trends
Compare attrition across departments and job roles
Track employee tenure and experience
Build interactive dashboards for HR decision-making
Generate business insights from HR data
